# dotfiles-AwesomeWM

My AwesomeWM 4.3 rice: a "glass" bar, i3-style keybindings, and three themes, each tied
to a wallpaper. Switching wallpaper switches the colors of awesome, alacritty, rofi and
the desktop HUD in one go.

Built for Arch, and in particular for Arch inside [JuNest](https://github.com/fsquillace/junest)
on 42 school workstations (no root, GNOME imposed).

## Contents

| Path | Role |
| --- | --- |
| `config/awesome/rc.lua` | awesome config: bar, keybindings, rules |
| `config/awesome/rice.lua` | the themes (wallpaper + palette) and the color export |
| `config/picom.conf` | blur, rounded corners, transparency |
| `config/alacritty/` | terminal, imports the `theme.toml` generated by `rice.lua` |
| `config/rofi/` | launcher, imports the `colors.rasi` generated by `rice.lua` |
| `config/LuminaHUD/` | [LuminaHUD](https://github.com/delmath/LuminaHUD): clock, weather, ISS, crypto, 42 |
| `bin/nog-awesome.sh` | freezes GNOME and starts awesome inside JuNest |
| `bin/gpurun`, `bin/chrome` | run an app with the GPU / the host's Chrome from JuNest |
| `wallpapers/` | the three theme wallpapers |

## Installation

```sh
git clone git@github.com:delmath/dotfiles-AwesomeWM.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

The script:

1. installs the packages with `pacman`, then `yay` (`luminahud-git` comes from the AUR);
2. symlinks `~/.config`, `~/.local/bin` and `~/Pictures/Wallpapers` entries to the repo —
   a file already in place is renamed to `.bak.<date>`, nothing is overwritten;
3. creates `~/Pictures/Screenshots`, an empty `~/.config/LuminaHUD/42.env` and the
   "Awesome (JuNest)" menu entry.

`./install.sh --no-packages` only does the symlinks.

Installed packages: `awesome picom rofi alacritty ttf-jetbrains-mono-nerd
papirus-icon-theme python libpulse maim xclip` and `luminahud-git`.

Since these are symlinks, editing `~/.config/awesome/rc.lua` edits the repo: all that is
left is `git commit` and `git push`.

### Starting awesome

- **Regular Arch**: pick awesome in your display manager, or put `exec awesome` in
  `~/.xinitrc`.
- **JuNest at 42**: launch "Awesome (JuNest)" from the GNOME menu (or run
  `~/.local/bin/nog-awesome.sh`). The script pauses GNOME, starts awesome on the same
  display, and resumes GNOME when you quit awesome (`Mod+Shift+e`).

### 42 blocks of the HUD

Create an application at <https://profile.intra.42.fr/oauth/applications/new>
(any redirect URI, no scope), then fill in `~/.config/LuminaHUD/42.env`:

```sh
FT_UID=...
FT_SECRET=...
FT_LOGIN=your_login
```

This file is not in the repo. The weather is set to Lyon: change `LATITUDE` and
`LONGITUDE` at the top of `config/LuminaHUD/scripts/hud.py`.

### Things to adapt

At the top of `config/awesome/rc.lua` (the "Programmes" section):

- `browser` points to `~/Applications/zen/zen`;
- `filemanager` is `dolphin` (not installed by the script);
- `lock_cmd` is `/host/usr/bin/ft_lock`, specific to 42 workstations.

The HUD is laid out for a 1920x1080 screen. Comments in the config files and the HUD
labels are in French.

## Keybindings

`Mod` is the Super key. `Mod+s` shows the full cheat sheet.

| Keys | Action |
| --- | --- |
| `Mod+Return` | terminal (alacritty) |
| `Mod+Space` | launcher (rofi) |
| `Mod+b` / `Mod+d` | browser / file manager |
| `Mod+q` | close the window |
| `Mod+j` `k` `l` `;` or arrows | focus left / down / up / right |
| `Mod+Shift` + the same | move the window |
| `Mod+1`…`6` | go to tag |
| `Mod+Shift+1`…`6` | send the window to tag |
| `Mod+Tab` / `Mod+Shift+Tab` | next / previous tag |
| `Mod+e` `w` `a` `f` | tile / max / fair / floating layout |
| `Mod+m` / `Mod+F11` | maximize / fullscreen |
| `Mod+Shift+f` | toggle floating |
| `Mod+Shift+w` / `Mod+Ctrl+w` | next / previous theme |
| `Print` | screenshot of the whole screen |
| `Shift+Print` or `Mod+Shift+s` | screenshot of a region |
| `Mod+Shift+x` | lock |
| `Mod+Shift+r` | restart awesome |
| `Mod+Shift+e` | quit awesome |

Screenshots are saved to `~/Pictures/Screenshots` and copied to the clipboard.

## Themes

| Theme | Wallpaper | Mood |
| --- | --- | --- |
| casque | `1280310.jpg` | space night, yellow |
| lune | `1296280.jpg` | warm grey, gold |
| néon | `1310342.jpg` | midnight blue, magenta and cyan |

To add one: drop the image in `wallpapers/`, run `./install.sh --no-packages` again, and
add an entry to `M.themes` in `config/awesome/rice.lua` (same keys as the others). The HUD
is tuned per theme in `config/LuminaHUD/config`.

## Uninstall

Remove the symlinks, then restore the `.bak.<date>` files if any:

```sh
find ~/.config ~/.local/bin ~/Pictures/Wallpapers -lname "$HOME/dotfiles/*" -delete
```
